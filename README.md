## 📌 Repository Overview
This repository contains the implementation and analysis of parallel **Sparse Matrix-Vector Multiplication (SpMV)** kernels. The project is divided into two deliverables, exploring both **Shared Memory** and **Distributed Memory** paradigms to optimize performance on High-Performance Computing (HPC) clusters.
